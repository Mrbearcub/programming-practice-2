# Практика 2 — 2D-платформер на Godot

## О проекте

Проект представляет собой небольшую 2D-игру на **Godot Engine 4.7.2** с использованием **C# и .NET 8**. Игрок может прыгать и стрелять по врагам. Противники и препятствия появляются справа за пределами экрана и движутся в сторону игрока.

## Как запустить

1. Установите Godot Engine версии **4.7.2 с поддержкой .NET** и .NET SDK 8.
2. Распакуйте архив проекта.
3. Откройте в Godot файл `project.godot`.
4. Дождитесь импорта ресурсов и сборки C#-скриптов.
5. Запустите проект клавишей **F6/F5** или кнопкой запуска проекта. Главная сцена — `level.tscn`.

## Игровая логика

- **Игрок** находится на уровне, может прыгать под действием гравитации и создавать пули.
- **Пули** летят вправо, наносят урон врагам и исчезают при столкновении с врагом/препятствием или при выходе за экран.
- **Враги** имеют запас здоровья. Получая урон, они теряют здоровье и уничтожаются при достижении нуля.
- **Препятствия** движутся в сторону игрока и уничтожают пулю при столкновении.
- **Спавнер** срабатывает по таймеру и выбирает случайный объект из заданного списка.
- **Летучая мышь** появляется на случайной высоте и движется по синусоидальной траектории.
- **Зомби** и **камень** появляются в заданной точке за правым краем экрана.
- При столкновении игрока с опасным объектом игра завершается.

## Основные классы

### `DamagingObject`

Базовый класс опасных объектов. Содержит скорость движения, виртуальный метод `Move(float delta)`, метод `GetSpawnPosition()` для получения позиции появления и обработчик выхода за экран.

### `Enemy`

Наследуется от `DamagingObject`. Хранит здоровье (`Health`), предоставляет метод `TakeDamage(float damage)` и удаляет врага, когда здоровье становится меньше или равно нулю.

### `Obstacle`

Наследуется от `DamagingObject` и используется как общий тип препятствий, с которыми взаимодействуют пули.

### `Field`

Получает список сцен в экспортируемом массиве `Objects`. По сигналу таймера выбирает случайную сцену, создаёт объект и устанавливает его позицию с помощью `GetSpawnPosition()`.

### `player`

Реализует гравитацию и прыжок, создаёт пулю при нажатии клавиши стрельбы и завершает игру при столкновении с объектом, наследующим `DamagingObject`.

## Настройка списка появляющихся объектов

1. Откройте `level.tscn` в редакторе Godot.
2. Выберите корневой узел `Level`.
3. В инспекторе найдите свойство `Objects` скрипта `Field`.
4. Добавьте или удалите сцены объектов, которые должны появляться случайным образом.

Период появления задаётся свойством `Wait Time` узла `Timer` в `level.tscn` (сейчас — `1.5` секунды).

## Примечания

- Параметры вроде здоровья, скорости, координат появления и скорости прыжка задаются в соответствующих C#-скриптах или переопределяются в инспекторе сцены.
- Каталоги `.godot/` и `.vs/` содержат локальные файлы редактора и сборки; для работы с проектом обычно достаточно исходных файлов, сцен и файла `project.godot`.
